## F1 — Flat spot is not flat *(done)*

**Changed:** `injection.py` — `_fine_wedge`, `wedge_peak_amplitude`,
`model_wedge_response`, `inject_dhi_anomaly`, `inject_dhi_anomaly_3d`.
`flat_spot_offset_ms` (an offset below the dipping top) replaced with
`contact_time_ms` (an absolute two-way time). In `inject_dhi_anomaly_3d`,
`contact_time_ms` is now derived once per injection from the footprint's own
structural relief (`crest_time_ms + contact_frac * relief_ms`, default
`contact_frac=0.5`), computed in a pre-pass before the per-voxel loop. Raises
if the footprint's relief is below `500/freq_hz` ms (half a Ricker cycle) —
too small for the contact to be a separable event from the top reflector.
The flat-spot spike is now emitted only where `top_time_ms < contact_time_ms`
(updip of the contact).

The 2D `inject_dhi_anomaly` has no horizon/relief concept (constant
`top_time_ms`), so it now takes `contact_time_ms` directly from the caller
and raises if `flat_spot=True` without one.

One notebook cell needed a manual update: `synthetic_dhi_generation.ipynb`
(cell id `841bf05c`) loops the 2D function over `SEVERITY_TIERS`, and
`tier4_obvious` has `flat_spot=True` — now passes an illustrative
`contact_time_ms` for that demo comparison.

**Verified:** reproduced the review's own check independently.

- Flat-spot event time across 3 simulated dip positions (top times 874/880/886ms,
  isolated by differencing wedge-with-flat-spot vs wedge-without): **900 → 902 → 900**
  (vs. the original bug's 904 → 908 → 916, which tracked the horizon 1:1).
- Downdip of the contact (top_time_ms=950 > contact=900): flat-spot
  contribution is exactly **0.0** — confirmed no event where there's no gas.

## F2 — Polarity reversal nulls the centre *(done)*

**Changed:** `injection.py` — `inject_dhi_anomaly_3d` and `inject_dhi_anomaly`.

3D: `polarity_reversal` now blends RC from `reflection_coefficient` (gas leg)
to `RC_WATER_SAND * water_leg_scale` (brine leg - real, weaker, opposite-signed,
never zero) across the same `contact_time_ms` introduced for F1, using a smooth
tanh transition rather than a hard linear ramp. The transition is keyed off
structural depth (`top_time_ms - contact_time_ms`), not lateral position in
the footprint, so it's anchored to the real fluid contact rather than the
footprint's geometric centre. `flat_spot` and `polarity_reversal` now share
one relief-derivation pre-pass (either flag triggers it), since a polarity
reversal and a flat spot are the same physical contact.

Blend width (`polarity_blend_ms`) is derived from the footprint's own average
dip rate (relief / footprint diameter) rather than a fixed constant, so it
scales with how steeply each specific footprint dips - "~2-3 traces" per the
review, translated into time via that footprint's own geometry.

2D `inject_dhi_anomaly` has no real horizon/depth, so the same non-zero-leg +
smooth-blend fix is anchored to lateral position (footprint centre) instead -
new `polarity_blend_frac` param (default 0.03) sets the transition width as a
fraction of the footprint's trace count.

**Verified:**

- Isolated the rc-blend formula directly (independent of wavelet convolution,
  which was muddying a first attempt at reading sign off the injected trace):
  stable at `-0.1545` (full gas RC) for `delta_t <= -6ms`, stable at `+0.0992`
  (full brine RC) for `delta_t >= +6ms`, smooth transition through `-0.0276` at
  `delta_t=0` (the contact itself) - **never zero**, unlike the original bug's
  exact `0.0` at the footprint's geometric centre.
- Real 3D injection (tier-4-like params, mock dipping horizon, contact landing
  exactly at the footprint's geometric centre by construction): centre-trace
  peak amplitude is `0.0397` (nonzero) vs. `0.0` in the original bug.
